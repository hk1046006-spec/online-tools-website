# public/images/

A place for static images that ship with the code (icons, illustrations, logos you want in version
control). Nothing in this build depends on it — the default logo and favicon live in
`public/assets/`.

Content photographs that the site owner can change are **not** kept here. They are uploaded through
the admin panel into `uploads/images/`, `uploads/banners/` or `uploads/logo/`, where each file gets a
random name, an optimised re-encode and a 400 px thumbnail.
